How do I get a token?
  1. Confirm your identity once at facebook.com/ads/library/api.
  2. Create a Meta developer app, open the Graph API Explorer and generate a user token.
  3. Paste it above. Meta's API returns political and social-issue ads everywhere, and all ads shown in EU countries. For other ads, paste the ad's link with “+ Add ad”.
